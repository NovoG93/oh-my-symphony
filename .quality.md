Factory commands emit English; Korean documentation examples must agree.
Graphical layout, touch targets, animation, checkout, accounts, and field
telemetry criteria do not apply to this local CLI surface. Copyable diagnostics,
clear recovery, input preservation, package integrity, and verification apply.
Live hosted model availability is separate from deterministic local proof.

The owner's approved scope requires completing necessary repair and verification.
Final qualification exposed startup, delivery data-loss, browser-proof
applicability, operator-diagnostic faults, and token-cancelled success state before
delivery. These necessary repairs remain
within the approved scope; the rounds include them without lowering any floor.
